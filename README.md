# Manaswi More — Interactive Portfolio

A responsive, pink illustrated developer portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally

1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For a local development server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Included

- Responsive single-page layout with Home, About, Skills, Projects, Experience, Education and Contact.
- Scroll reveal animations, active navigation and mobile menu.
- Local M.AI FAQ demo with answers grounded in the portfolio content.
- Resume PDF download.

## Before publishing

- Replace the sample project GitHub links with each project's actual repository and live-demo URLs.
- Review the resume PDF and contact details before making the site public.
- The M.AI assistant is currently a local FAQ demo, not a live LLM integration. To make it a real AI assistant, connect the frontend to a secure backend endpoint; do not put API keys in browser JavaScript.
- The illustrated hero asset is a decorative concept image. Replace it with your preferred final avatar artwork if desired.

## Deploy

You can deploy this folder to GitHub Pages, Netlify or Vercel as a static site.
